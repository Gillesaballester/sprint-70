# Sprint 70

Refonte du site Sprint 70 : dépannage, réparation, vente d'électroménager et pièces détachées.

## Démarrage

```bash
pnpm install
pnpm dev
```

Le projet utilise Next.js, TypeScript et Tailwind CSS.

## Périmètre MVP

- Accueil orienté conversion
- Parcours de demande de dépannage
- Catalogue d'électroménager et demandes d'information
- Demandes de pièces détachées
- Pages Sprint 70 et contact
- SEO local, performance et accessibilité
